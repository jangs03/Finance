# 누수(look-ahead) 전면 재검토

> 범위: 데이터 → feature → 정답 → 분할 → 학습·튜닝 → 평가 → 캐시 → 제출, 2026-10-10
> 재실행: `python eda/leakage_audit.py` (결과 `runs/audit/`), `python -m exp check e0`

## 결론

**feature·정답·분할·학습 경로에서는 미래 정보가 섞인 흔적을 찾지 못함.** 가장 민감한 검정(일부러 누수시킨 feature 를 양성 대조군으로 둔 rest 검정)에서도 실제 feature 는 모두 정상 범위였음.

남아 있는 오염은 **feature 수준이 아니라 "선택" 수준**임: EDA·lockbox 노출(장부에 기록), 다중 비교, 종목 선정의 생존 편향. 아래 4절.

## 2. 실측 검정 (DEV, 22,400행)

### A. 장 시작 후 움직임(rest) 검정
rest = 대상일 수익률 − 프리마켓 갭 (로그). 09:30 이후 움직임이라 원래 알 수 없는 값임. 이것을 "예측"하는 feature 가 있으면 누수 의심.

| 항목 | Spearman ρ(·, rest) |
|---|---|
| **양성 대조군: 일부러 누수시킨 10:30 가격 갭** | **+0.556** |
| 프리마켓 갭 `gap_pct` | −0.067 |
| 그 밖의 feature 최대 (`surp_pct_w`, n = 357) | +0.13 (z = 2.6) |
| 그 밖의 feature 대부분 | \|ρ\| < 0.02 |

- 누수가 있으면 ρ 가 +0.5 수준으로 나옴. 실제 feature 는 모두 그보다 한 자릿수 이상 작음
- 갭 계열의 약한 음의 상관(−0.06 ~ −0.07, z ≈ −6)은 **누수가 아니라 되돌림**임: 큰 갭 뒤 장중에 일부 되돌아가는 현상 (EDA 에서도 확인). 누수라면 부호가 양수여야 함
- `surp_pct_w`(실적 서프라이즈)의 +0.13 은 실적 발표 후 같은 방향으로 더 가는 알려진 현상(PEAD)과 일치하고, 표본이 작아 유의하지 않음 (z < 3). 실적 시각 자체는 C 에서 검증

### B. 가격 시각

| 항목 | 값 | 해석 |
|---|---|---|
| ρ(갭, 시가 갭) | 0.709 | 갭은 개장가 움직임을 미리 보여 줌 |
| ρ(갭, 장중 수익률 = 종가/시가) | −0.008 | 갭에 장중 정보가 없음 ✅ |
| 대체값(post 봉) 사용 비율 | 0.09% | — |

### C·D. 이벤트 시각
known_at 이 실제보다 이르면 가격 반응이 반영 대상일(T)이 아니라 그다음 날(T+1)에 나타나야 함.

| 실적 | 건수 | \|갭\| T | \|갭\| T+1 | 평소 \|갭\| |
|---|---|---|---|---|
| 개장 전 발표 | 201 | **2.98%** | 0.55% | 0.64% |
| 장 마감 후 발표 | 156 | **5.06%** | 0.74% | 0.64% |

→ 반응이 정확히 T 에 나타남 ✅. 애널리스트(3,066건)도 T+1 에 반응이 몰리지 않음 ✅

### E. 뉴스 시각
16시 실적 발표 기준으로 그 회사가 언급된 "실적" 기사의 도착 시각을 봄.

- 발표 전에 찍힌 기사는 대부분 **미리보기**("Reports Q1 Results Tomorrow", "Ahead Of Earnings")
- 그 대상일 창(발표일 09:30)보다 앞서 찍힌 "실제 결과" 표현 기사는 정규식으로 76건(전체 결과 기사의 0.2%). 그중 중복을 뺀 15건을 직접 읽어 보니 **모두 미리보기**였음 (나머지 61건은 직접 확인하지 않음)
- 발표 몇 시간 전에 실제 결과를 담은 기사가 찍힌 사례는 있음 (예: DELL "Q4 EPS Beats" −1.0h, CRM "Revenue Beat" −5.5h). 뉴스 시각이 약간 이르게 기록된 것으로 보이지만, 실적과 **같은 대상일 창 안**이라 09:30 cutoff 를 넘지 않음
- 다만 이런 시각 오차가 창 경계(전날 09:30)를 넘는 경우가 드물게 있을 수 있음. A 의 rest 검정에서 뉴스 feature 가 rest 를 예측하지 않으므로(\|ρ\| < 0.02) 실질 영향은 없다고 판단

### F. Reddit 시각
`created_et` = `created_utc` 의 미국 동부시간 변환, 표본 5만 건 오차 0초 ✅

### G. 분할
fold A·B·C 모두 학습 마지막 날과 평가 첫날 사이 15~17일, 처음 보는 종목 학습 행 0, lockbox 행 0 ✅

## 3. 이번 재검토에서 다시 확인한 기존 수정

| 문제 | 상태 |
|---|---|
| 09:00 pre 봉(09:30 에 완성)을 넣으면 갭 상관이 0.539 → 0.579 로 부풀려짐 | 제외 규칙으로 고정, E0 로 매번 확인 |
| Reddit `score`·`n_comments` 는 36시간 뒤 값 | 읽지도 않음 |
| 같은 날짜를 공유하는 종목 holdout 은 날짜 단위 feature 를 통해 새어 성능이 부풀려짐 (Reddit +0.10) | 판단에서 제외, 시간 + 종목 holdout 만 사용 |
| ATR 을 EWM 으로 계산하면 전체 이력에 의존해 하루 계산과 달라짐 | 14일 단순평균으로 변경 |

## 4. 남아 있는 오염 (feature 가 아닌 선택 수준)

| 오염 | 내용 | 영향 | 대응 |
|---|---|---|---|
| **lockbox 사전 노출** | EDA 가 전체 기간(lockbox 포함)을 봄. k = 5.25 를 2026 데이터로 고름. `main.py eval` 로 lockbox 점수 1회 확인 | 갭 규칙 계열의 lockbox **절대 점수**는 처음 보는 구간 추정이 아님 | `exp/lockbox_ledger.json` 에 기록. 보고서는 paired Δ 를 주 결과로 |
| **설계 상수** | `VOL_FLOOR`, `BIG_GAP`, `TONE_TAIL`, 템플릿·사건 정규식 등은 전체 기간 데이터를 보고 정함 | 정답을 보고 정한 값은 아니라 영향 작음 | 보고서에 명시 |
| **다중 비교** | 후보 약 50개를 같은 DEV 에서 비교 | DEV 1위 점수는 과대평가 (실제로 T1-vol 은 lockbox 에서 재현 안 됨) | 최종 선택은 사전 규칙, 텍스트 단계는 Holm 보정 |
| **생존 편향** | 50종목은 현재(2026) 기준으로 고른 대형주. 그사이 상장폐지·편출된 종목은 없음 | 모든 모델에 똑같이 작용. 처음 보는 10종목도 비슷하게 골랐다면 영향 작음 | 보고서에 한계로 명시 |
| **LLM 사전 지식** | 2024~2026 사건을 학습한 LLM 은 결과를 알 수 있음 | 연구용 LLM feature 에만 해당 (제출 모델엔 없음) | 익명/원문 비교 + placebo 시점 테스트 (T6) |
| **FinBERT** | `ProsusAI/finbert` 는 2019 년 데이터로 학습 → 이후 사건 지식 없음 | 해당 없음 | — |

## 5. 앞으로 지킬 것

- feature 를 추가할 때마다 `python -m exp check e0` (학습·predict 일치)와 `python eda/leakage_audit.py` (rest 검정) 를 같이 돌림
- rest 검정에서 **양의** \|z\| > 3 이 나오면 원인을 확인하기 전까지 채택하지 않음 (음의 상관은 되돌림일 수 있음)
- lockbox 구간 점수는 더 보지 않음 (`main.py eval` 은 자동으로 막힘)
